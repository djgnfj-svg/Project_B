# 코옵 보스 패턴 설계 — "몰락한 망령" (카멘식 키 입력 파훼)

> 보스 = 어둠 망령 보스(`data/enemies/wraith_boss.tres`). 2인 협동 전용 — **혼자서는 반드시 실패**하도록 설계.
> 참고: 로스트아크 카멘 3/4관문 (키 눌러 파훼하는 기믹). GDD 원칙 준수: 긴 텔레그래프·읽고 대응·프레임 반응 금지(웹 지연 공정성).
> 작성 2026-07-24. 상태 = 설계 승인 대기.

---

## 0. 설계 규칙 (모든 패턴 공통)

- **혼자 하면 죽는다** — 각 패턴은 A/B 역할이 갈리고, 한쪽이 자기 역할을 안 하면 상대(또는 파티)가 죽는다.
- **긴 텔레그래프** — 파훼 입력 창은 최소 1.2초 이상 (웹 지연에서도 공정). 프레임 단위 반응 금지.
- **키 입력 파훼** — 파훼는 "정해진 키를 정해진 창에 누른다". 새 입력 액션 필요 (아래 §4).
- **호스트 권한** — 파훼 성공/실패 판정은 호스트가 확정, 결과만 브로드캐스트 (rules §3). 게스트는 입력을 호스트에 전송.
- **연출은 표시 전용** — 텔레그래프·이펙트는 각 클라 로컬 (feel 계층).

## 1. 패턴 목록 (파훼 난이도·구현 순)

### P1. 영혼 결속 — 「직면(直面)」 ★쉬움·먼저 구현
카멘 "직면" 오마주. 보스가 한 명(A)을 초록 눈으로 **응시(마킹)**하고 3초 예고.
- **A의 역할:** 예고 동안 **보스를 바라보는 방향으로 서서 `F(직면)` 키를 누른다.** (마우스로 보스 쪽 조준 + F)
- **B의 역할:** B는 이때 **A와 보스 사이 직선에 들어가면 안 됨** (가로막으면 A의 직면이 무효 → 실패).
- **실패 시:** A가 직면 안 하거나 B가 가로막으면 → **A 즉사급 피해**.
- **파훼:** A가 보스 응시 + F, B는 라인에서 비켜서기.
- **애니:** 보스 눈 발광(cast). / **구현:** 마킹 + 방향 판정 + F 입력 — 신규 코드 中.

### P2. 좌우 협살 — 「갈라서기」 ★쉬움·기존 시스템으로 됨
보스가 양쪽에 거대 부채꼴 2개 동시 예고 (`swing` 콘 좌·우). 한 명이 둘 다 못 피함.
- **A의 역할:** 왼쪽 안전지대로 **구르기(Shift)로 회피.**
- **B의 역할:** 오른쪽 안전지대로 회피.
- **실패 시:** 둘이 같은 쪽에 몰리면 반대쪽 콘에 안 맞지만, 겹친 사각에서 **동시 피격 → 큰 피해.** (혼자면 반드시 한쪽 맞음)
- **파훼:** 좌우로 갈라져 각자 회피.
- **구현:** **기존 `BossPatternDef` 콘 2개로 즉시 가능** (wraith_boss.tres에 이미 골격).

### P3. 소울 케이지 — 「구속·구출」 ★중간
카멘 구속 오마주. 보스가 B를 초록 영혼 감옥에 가둠 (행동 불가 + 초당 피해, 5초 후 사망).
- **B의 역할:** 갇힌 채 **`구르기(Shift)를 연타`해 창살을 흔든다** (게이지 일부 채움 — 혼자선 못 깸).
- **A의 역할:** 감옥(Area)에 **근접해 공격(좌클릭)으로 창살 HP를 깎는다.** A 공격 + B 연타 합쳐야 제한시간 내 파괴.
- **실패 시:** 5초 안에 못 부수면 **B 사망.**
- **파훼:** A가 달려가 감옥 때리기 + B 연타.
- **애니:** 보스 손 뻗기(cast). / **구현:** 상태이상(구속) + 감옥 엔티티 + 게이지 — 신규 코드 中.

### P4. 봉인진 — 「동시 점화」 ★중간
보스 무적 + 바닥에 초록 마법진 2개 동시 등장. 잔몹(코볼트) 소환으로 압박.
- **A의 역할:** 왼쪽 마법진 위에 서서 **`F` 유지 (채널링).**
- **B의 역할:** 오른쪽 마법진 위에서 **동시에 `F` 유지.** 두 진이 **동시에** 활성돼야 무적 해제.
- **실패 시:** 한쪽만 밟으면 안 풀리고, 소환된 잔몹에게 계속 두들겨 맞음 → 시간 끌면 전멸.
- **파훼:** 각자 하나씩 밟고 동시에 F. (한 명이 두 진 못 밟음 — 멀리 떨어져 있음)
- **애니:** 보스 무적 진입(cast, 팔 벌림)·해제(비틀). / **구현:** interact 영역 2개 + 동시 판정 + 소환 — 신규 코드 中상.

### P5. 카운터 — 「돌진 반격」 ★중간·카멘식 핵심
카멘 카운터 오마주. 보스가 A를 향해 **초록 돌진** 예고(1.5초, 눈 번쩍 = 카운터 신호).
- **A의 역할:** 돌진 창에 맞춰 **`구르기(Shift)`로 회피** (몸으로 유인만).
- **B의 역할:** 보스 돌진 궤적 **측면에서 `Q(반격 스킬)`을 눌러 카운터** → 보스 그로기(경직 + 딜찬스).
- **실패 시:** B가 카운터 안 하면 보스가 A를 관통 → **A 큰 피해 + 그로기 없음(딜찬스 상실).**
- **파훼:** A 유인 회피 + B 측면 카운터.
- **애니:** 돌진(신규 dash)·그로기. / **구현:** 돌진 이동 + 카운터 입력 창 + 그로기 상태 — 신규 코드 中상.

### P6. 별의 낙하 — 「구슬 나르기」 ★어려움·카멘식
카멘 구슬/메테오 오마주. 보스가 머리 위로 별(초록 구슬) 2개 생성, 5초 후 낙하 = 광역 즉사.
- **A/B 공동:** 각자 구슬 하나에 **근접해 `E(운반)`로 집어 든다** → 아레나 가장자리 **표식 위로 옮겨 `E`로 내려놓기.**
- **실패 시:** 하나라도 제자리에 못 놓으면 그 구슬이 아레나 중앙에 낙하 → **파티 전원 즉사급.**
- **파훼:** 둘이 각자 구슬 하나씩 운반 (혼자선 2개 못 옮김 — 시간 부족).
- **애니:** 보스 소환(cast). / **구현:** 운반 상태(이동속도↓) + 표식 판정 + 낙하 타이머 — 신규 코드 上.

## 2. 페이즈 구성 (제안)

| 페이즈 | HP | 등장 패턴 | 성격 |
|---|---|---|---|
| **1페이즈** | 100~50% | P2 좌우협살 · P1 직면 · (기본 슬램/노바) | 조작·위치 협동 학습 |

## 3. 미결 (승인·결정 필요)

- **솔로 처리:** 코옵 강제 패턴(P3/P4/P6)을 솔로에서 어떻게? (a) 솔로는 보스 스킵/약화판 (b) 솔로 전용 대체 기믹. → 결정 필요.
- **새 입력 액션:** `직면`·`반격(Q)`·`운반(E)` 신설 (§4). GDD §5 조작에 QER 스킬 예약돼 있으니 정합.
- **파훼 실패 페널티 강도:** "즉사급"인지 "큰 피해"인지 — 사용자 실기 튜닝.
- **네트워크:** 각 파훼 = 새 net 메시지(입력 전송 + 결과 확정). reviewer 네트워크 리뷰 필수.
