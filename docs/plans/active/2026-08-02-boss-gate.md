## 1. ① 진입 통로 — 맵을 서쪽으로 넓힌다 (⒜)

### 왜 ⒝(아레나를 오른쪽으로)가 안 되나
아레나 표지는 768px 고정 PNG이고, `verify_boss` ⑵가 **아레나를 `body_radius`(63)만큼 부풀린 영역이 전부 통행 가능**할 것을 요구한다 → 서쪽으로 129까지는 반드시 열려 있어야 한다. 통행 가능 동쪽 끝이 1072이므로 아레나를 오른쪽으로 밀 수 있는 여지는 **최대 49px**이다. 복도가 안 나온다.

### 왜 "지금 맵 안에서" 안 되나 — 공허(void) 여유가 없다
`stage.gd`는 카메라 제한을 안 건다. `verify_boss` ⑶이 요구하는 여백은 `ZOOM_WIDE`(0.8) 기준 가로 400 + 셰이크·반동 10.67 − 플레이어 반폭 6 = **402.67px**인데, 현재 서쪽 테두리는 464px이다 → **남는 슬랙이 59.33px뿐**. 남·북은 42.33px. 어느 방향으로도 의미 있는 복도를 팔 수 없다.

### 처방 — 서쪽으로 12칸(384px) 통째로 민다

```python
# scripts/gen_stage.py — BOSS 스펙
"size":   (72, 36),        # 60 → 72  (1920 → 2304 px)
"origin": (-24, -8),       # -12 → -24 (맵 서쪽 -384 → -768)
"edge":   (27, 9, 15, 9),  # 🔴 (좌, 상, 우, 하) — 좌만 12칸 두꺼워진다
"open":   [(15, 27, 17, 20)],  # 정점 인덱스 (x0, x1, y0, y1) — 이 사각을 통행 가능으로 뚫는다
```

**통행 가능·맵을 같은 384px씩 밀었으므로 공허 여유가 한 픽셀도 안 변한다**(아래 실측이 그 검산이다).

| | 현행 | 제안 | 필요 | 여유 |
|---|---|---|---|---|
| 맵 | (−384,−256)~(1536,896) | **(−768,−256)~(1536,896)** | — | — |
| 통행 가능 | (80,16)~(1072,624) | **(−304,16)~(1072,624)** | — | — |
| 공허 서 | −384 | **−768** | −708.67 | **59.33** (현행과 동일) |
| 공허 북/동/남 | | **무변경** | | 42.33 / 59.33 / 42.33 |
| 셀 수 | 2160 | **2592** (+20%) | | |

- **동·북·남 경계와 아레나 영역은 한 픽셀도 안 움직인다.** `arena_rect` 메타(192,116,768,416)도 그대로다 → **횡단 돌진(bossdash) 기하는 무접촉.**
- 복도 = **월드 x [−304, 80] · y [272, 400] (높이 128px)**. `stage_cliff.tres`라 복도 양옆은 낭떠러지(lower) = 협곡 위 바위 다리로 읽힌다.
- **스폰** `spawn_base` (240,340) → **(−256, 340)**. P2 = (−176, 340). 둘 다 복도 안(실측 OK).
- 걷는 거리 = 스폰 −256 → 트리거 224 = **480px ≈ 4.8초**(전사 이속 100).

### 생성기 코드 변경 (물가·낭떠러지 칸에 완전 항등)

| 함수 | 변경 | 항등 근거 |
|---|---|---|
| `edges(spec)` | int / 2-튜플 / **4-튜플(l,t,r,b)** 모두 받게 | 물가·낭떠러지는 `edge: 2`(int) 그대로 |

| `dims`·`solid_at`·`passable_bounds`·`tile_map_data` | **무변경** | 전부 `dims()`/`v`만 본다 |

## 2. ② 트리거 — 좌표 임계 · 호스트 확정 · **전원**

### Area2D를 쓰지 않는 이유 (🔴 이게 이 절의 핵심이다)
- Area2D는 **각 클라의 로컬 물리 몸**에서 발화한다 → 게스트가 로컬로 상태를 확정하게 된다(rules §1 위반).
- 호스트에게 게스트의 물리 몸은 **보간된 표시 아바타**다. 거기에 Area2D를 달면 판정이 `net_anchor()`가 **아닌** 좌표계에서 나온다 — §3이 반복해서 값을 치른 그 함정("판정과 표시가 다른 좌표를 지난다")이다.
- 좌표 임계는 호스트의 **다른 모든 판정과 같은 소스**(`net_anchor()`)를 쓴다. ✅

### 조건

```gdscript
# BossGate (호스트 전용) — 매 물리 프레임
# 🔴 "생존 피어 **전원**"이다. 한 명만으로 닫으면 복도에 남은 파트너가 갈라진다.
var alive := 0
for node in get_tree().get_nodes_in_group("player"):
    # 🔴 씬 스왑 유령 차단 — 자기 씬 하위만 (rules §5)
    if not get_parent().is_ancestor_of(node): continue
    var p := node as PlayerActor
    if p == null or not p.is_alive(): continue
    alive += 1
    if p.net_anchor().x < trigger_x: return   # 아직 안 넘은 피어가 있다
if alive < 1: return                          # 아무도 없으면 안 닫는다
_close()
```

- **`net_anchor()`(낡은 좌표)를 쓰는 것이 안전한 방향이다** — 게스트의 진짜 위치는 앵커보다 **더 동쪽**일 가능성이 높으므로(전진 중), 앵커 기준 판정은 "덜 닫히는" 쪽으로 틀린다.
- **한 번 닫히면 재무장 없음**(`_armed`).
- AFK 파트너가 있으면 진행이 멈춘다 — 2인 협동에서는 *"파트너를 기다린다"* 가 옳은 동작이라고 판단했다. 4인에서도 성립하지만 인원이 늘수록 대기 확률이 오른다(§8).

### 좌표 여유 (실측)

| | 값 |
|---|---|
| 게이트 바위 중심 x | **60** · 반경 24 → 동쪽 끝 **84** |
| 트리거선 x | **224** (아레나 표지 서단 192에서 32px 안쪽) |
| 여유 | **140px** ≥ `LAG_MAX_LEAD_DIST` **115** ✅ |

**왜 115가 기준인가**: 앵커가 최대로 낡을 수 있는 거리가 그 상한이다. 트리거 시점에 앵커가 224여도 실제 위치는 최악 224 − 115 = 109 > 84 → **닫히는 순간 게이트 위에 서 있는 피어가 원리적으로 없다.** 이 부등식을 생성기가 트립와이어로 잠근다(§7).

**화면에 보이나**: 줌 1.5에서 가시 반폭 213px. 트리거(224)에서 게이트(60)까지 164px → **닫히는 것이 화면 안에서 보인다.** ✅

## 3. ③ 막는 것 — 기존 `BossRock` 5개 (신규 아트 0)

### 왜 새 아트를 안 만드나
`boss_rock.png`(320×64, 5프레임)는 이미 **정적 몸 + 콜리전 + 낙하 연출 + 착지 먼지 + 파괴 애니**를 다 갖고 있다. 낭떠러지 협곡 복도가 **낙석으로 봉쇄된다**는 그림은 이 타일셋 테마에 정확히 맞고, 낙하 애니가 그대로 "쿵" 하고 닫히는 연출이 된다. rules §0(도형 금지 · 스프라이트로)도 충족한다.

### 배치 — 생성기가 복도 기하에서 **유도**한다 (미러 금지)

| 항목 | 값 | 유도 |
|---|---|---|
| 개수 | **5** | `ceil(H / s_max) + 1` |
| y | 272 · 304 · 336 · 368 · 400 | 복도 상·하단을 포함해 균등 |
| 간격 | 32 | `H(128) / (n−1)` |
| 최소 띠 두께 | **35.78px** | `2·√(r² − (s/2)²)` |
| 필요 두께 | **20.7px** | 플레이어 폭 12 + 최대 프레임 변위(구르기 260/60 = 4.33) × 2 |

두 원의 중심 거리 32 < 2r(48)이므로 **틈이 0이고**, 가장 좁은 곳에서도 35.78px의 정적 몸이 있어 12px 플레이어가 프레임당 4.33px로 뚫을 수 없다. 이 부등식도 생성기가 잠근다.

시각적으로는 프레임 64px × `scale` 1.45 = **92.8px 바위 5개가 32px 간격**이라 겹쳐 쌓인 잔해 벽으로 읽힌다(복도 벽 밖으로 삐져나오는 것은 자연스러움).

### `ttl` — 🔴 `boss_rock.gd` 한 줄만 고친다

```gdscript
# 현행: if _age >= _ttl: _despawn()
# 제안: if _ttl > 0.0 and _age >= _ttl: _despawn()      # ttl ≤ 0 = 영구(게이트)
```
- 낙석(P4)은 `ttl = 10.0`을 넘기므로 **완전 항등**. 0 이하를 넘기는 호출부는 현재 없다.
- 거대한 ttl(1e9)을 넘기는 우회는 **쓰지 않는다** — 데이터에 거짓말을 심는 쪽이 다음 사람에게 더 비싸다.

### 🔴 돌진이 게이트를 부술 수 있나 — 없다 (검산)
`_dash_rock_collision()`은 **물리 충돌**(`get_slide_collision`)로만 바위를 찾는다. 횡단 돌진의 서쪽 끝은 `_cross_segment`가 `arena_rect.x + body_radius` = 255(중심)이고 보스 몸 왼쪽 끝은 **192**다. 게이트 동쪽 끝은 **84** → **108px 여유**. `CHARGE_APPROACH`도 그 시작단까지만 걷는다. 생성기가 이 부등식도 잠근다.
⚠ 설령 부서져도 **갈라지지 않는다** — `rock_break_local` → `G_ROCK_BREAK`가 양쪽을 같이 shatter시킨다(호스트만 화면이 달라지는 경로가 없다).

## 4. ④ 트리거 전 보스 — `gate_dormant` 상태 게이트

`aggro_range`는 추격·리시(`LEASH_MULT`) 판정의 단일 소스라 **손대지 않는다.** 대신 `coop_locked`와 **똑같은 자리·똑같은 모양**의 게이트를 하나 더 둔다.

```gdscript
# boss.gd — 선언부. 🔴 기본값 false = **도입 전과 완전 항등**(BossGate 없는 씬·시험장·랩 무영향)
var gate_dormant: bool = false   # 보스방 게이트가 아직 안 닫혔다 — 외부(BossGate)가 설정

# boss.gd _host_ai() — `coop_locked` 가드 **바로 위**
if gate_dormant:
    velocity = Vector2.ZERO
    return
```

- 이 위치면 **패턴 선택·추격·페이즈2 자동 늪이 전부 함께** 멈춘다(= `coop_locked`가 이미 증명한 자리).
- 보스는 `_ready`의 `_play(&"idle")` 그대로 **아레나에 서 있다**. 게스트도 `mpos`가 안 움직이니 같은 그림 = **표시 축 네트워크 0**.
- **등 돌리기는 채택하지 않았다** — `_face_dir`은 호스트 로컬이고 게스트는 갱신하지 않아 **호스트만 뒤통수, 게스트는 정면**이 된다(에러 없는 갈라짐). 그 축을 맞추려면 네트워크가 붙는다.
- 트리거 시점에 보스는 x 760, 플레이어 224 → 거리 536 < 600이라 **깨자마자 다가온다**. "문이 닫히고 → 어둠 속에서 보스가 걸어 나온다"가 공짜로 나온다.

### 🔴 같이 재워야 하는 것 — `CoopAuthority` (이걸 빠뜨리면 조용히 죽는다)
`coop_authority.gd`는 `_ready` 후 **`FIRST_DELAY_S` = 3.0초**에 첫 코옵 파훼를 발동한다. 복도를 4.8초 걷는 동안 **2.2초 시점에 복도 한가운데서 「별의 낙하」가 터진다** — 안전지대 표식이 아레나 안에 찍히면 도달이 불가능해 **즉사**한다.

```gdscript
# coop_authority.gd — 🔴 기본 true = 도입 전과 완전 항등(시험장·랩 무영향)
var armed: bool = true
# _process()의 호스트 카운트다운 게이트에 한 항 추가:
if not armed or not Net.is_host() or _alive_peer_ids().is_empty(): return
```
카운트다운은 **이미 호스트 전용**(`coop_authority.gd:180`)이라 게스트 갈래는 손댈 것이 없다.

## 5. ⑤ 네트워크 — 🔵 **신규 kind 0개**

### 기존 경로에 데이터로 얹을 수 있나 → **얹을 수 있다**

게스트가 알아야 하는 것을 세어 보면 **딱 하나**다:

| 무엇 | 게스트가 알아야 하나 | 왜 |
|---|---|---|
| 게이트가 닫혔다(= 지형이 생겼다) | 🔴 **반드시** | 안 맞으면 *"호스트는 막혔는데 게스트는 뚫려 있다"* = `G_ROCK_BREAK`가 값을 치른 그 결함 클래스 |
| 보스가 깨어났다 | ❌ **불필요** | 보스 AI는 **호스트 전용**이다. 게스트 보스는 `mpos` 꼭두각시라 "깼다"는 곧 "움직이기 시작했다"로 저절로 보인다 |
| `CoopAuthority` 무장 | ❌ **불필요** | 카운트다운이 호스트 전용이다 |

즉 필요한 것은 **"호스트가 확정한 정적 지형을 전원에게 스폰"** 하나뿐이고, **그게 정확히 `G_ROCK`이 하는 일이다.**

```gdscript
# BossGate._close() — 호스트만
var rocks: Array = []
for i in n:
    rocks.append(["gate:%d" % i, gate_x, y0 + spacing * i, rock_radius, 0.0])   # ttl 0 = 영구
EventBus.rock_spawn_local.emit(rocks)   # → RockField: 로컬 스폰 + G_ROCK 브로드캐스트
```

**공짜로 따라오는 것**: `stage_token` 가드(유령 스폰 차단) · `from_id == HOST_ID` 검증 · 신뢰 채널(`RTC_FAST_KINDS` 밖이라 유실 없음) · 중복 스폰 가드(`_rocks.has(rid)`) — **전부 이미 netreview를 통과한 경로다.**

**rid 충돌 없음**: 보스 낙석은 `"%s:rock:%d" % [eid, seq]` = `boss1:rock:1`, 게이트는 `gate:0`~`gate:4`.

### 수치를 싣나 → **좌표·반경만** (그 경로가 원래 싣는 것)
`G_ROCK`의 `rk` 튜플은 원래 `[rid, x, y, r, ttl]`이다. 게이트도 같은 형식을 쓴다 — **필드를 하나도 늘리지 않는다.** 트리거선·복도 기하·보스 각성은 **한 바이트도 안 나간다**(각자 로컬 씬에서 리졸브 = `peer_weapon_id`·`projectile_params` 철학).

### 표시 손맛(화면 흔들림) — 표시 전용, 네트워크 0
게이트 낙석은 각 클라가 **자기 화면에서** 흔들린다:
- 호스트: `_close()` 안에서 `EventBus.screen_shake.emit(GATE_SHAKE)`.
- 게스트: `net_msg`의 `G_ROCK`을 **관찰만** 해서 `rk`에 `gate:` 접두 rid가 있으면 emit. 🔴 **상태를 확정하지 않는다**(스폰은 `RockField`가 한다) — rules §2 손맛 계층 그대로.

⚠ 소리는 v1에서 **넣지 않는다** — 낙석 전용 SFX id가 없고 `weapon_impact` 훅을 전용(轉用)하면 의미가 갈라진다(§10-3).

### 🔴 netreview 필요: **예**
신규 kind는 0이지만 **호스트 권한 브로드캐스트에 두 번째 발신자가 생긴다.** 봐야 할 축: ⑴ 게스트가 `rock_spawn_local`을 못 emit하는가 ⑵ 트리거 판정이 `net_anchor()`인가 ⑶ 유실 채널에 안 들어갔는가 ⑷ 재합류 창(§8).

### 🔴 ⓐ 구현 중 발견: **P3 돌진이 게이트를 부순다** (설계에 없던 결함)

설계 §3은 *"횡단 돌진의 서쪽 끝이 게이트에서 108px 못 미치므로 안전"* 이라고 검산했는데, **그 검산은 횡단(cross) 돌진만 본 것이었다.** 기존 P3(`charge` 패턴 · `is_charge = true` · `breaks_rock` 없음)는 **플레이어를 향해** 돌진한다(`use_max_dist` 420 · `charge_travel_max` 260) — 게이트 앞에 선 플레이어를 쫓아오면 `_dash_rock_collision`이 게이트 바위를 물고 `_enter_charge_hit` → `_break_rock`으로 **한 칸을 부순다.**

5개 중 하나가 빠지면 이웃 간격이 32 → 64px가 되어 겹침이 사라지고 **16px 틈**이 열린다. 플레이어(12px)는 빠져나가는데 보스(충돌 반경 48)는 못 따라가 **싸움이 성립하지 않는다.** 양쪽 클라가 `G_ROCK_BREAK`로 같이 부수므로 **갈라지지도 않고 에러도 없다** — 그냥 조용히 게임이 망가진다.

**처방 = 영구 바위를 `"boss_rock"` 그룹에서 뺀다** (`boss_rock.gd`).

🔴 **커밋 `07b5b8c`(2026-08-02, 횡단 돌진 삭제) 이후 이 처방이 «유일한» 방어가 됐다.** 그 커밋은
`data/enemies/wraith_boss.tres`에서 `cross` 패턴(`breaks_rock = true`·아레나에 묶임)만 지웠고,

쪽**이라, 설계 §3의 「아레나 경계에서 108px 여유」 논거는 **더 이상 어떤 패턴도 안 덮는다.**

## 15. 항등 증명 — 물가·낭떠러지 칸

생성기 일반화(`edges()` 4-튜플 · `open`)가 새지 않았음을 **바이트 단위**로 확인했다.

```
재생성 전: 4bed81b15e3929c197331982ae634c15  stage_1.tscn
           68ea5da3fdd023d375bb717a6e0267fc  stage_2.tscn
재생성 후: 4bed81b15e3929c197331982ae634c15  stage_1.tscn   ← 동일
           68ea5da3fdd023d375bb717a6e0267fc  stage_2.tscn   ← 동일
git diff --name-only -- src/stage/  → stage_1/stage_2 **미출현**
```

보스방 재생성은 **멱등**이다(2회 실행 md5 동일). 씬 diff = `load_steps` · 새 ext_resource · Ground 타일 데이터 · `spawn_base` · `BossGate` 블록 **뿐**.

## 16. 🔴 남은 사각 (리드 판단 필요)

1. **`run_tests.sh`의 파스 체크가 새 파일(untracked)을 안 본다** — `git diff --name-only HEAD`라 `git add` 전의 신규 `.gd`가 통째로 빠진다. **새 씬 글루 파일이 가장 위험한 경우**인데(스위트가 preload를 못 하니 파스 체크가 유일한 방어) 정확히 그때 꺼진다. 이번엔 손으로 돌려 6개 전부 통과시켰지만, 처방은 `git diff HEAD` → `git ls-files -mo --exclude-standard`다. **하네스 변경이라 리드 몫.**
2. **`gate_dormant`·`armed` 대입이 정적으로 검증되지 않는다** — `boss.gd`·`coop_authority.gd`가 `-s`에서 컴파일이 안 돼 타입 해석이 무너지므로, 필드 이름을 오타 내도 파스 체크가 조용히 통과한다. 지금 방어는 스위트의 **소스 텍스트 단정** 2건뿐이다(그게 rules §3 「씬 글루 사각」의 표준 대응이다).
