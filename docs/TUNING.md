# 튜닝 노브 — "이게 어색한데 어디를 만지지?"

플레이하다 어색한 게 보이면 **증상으로 이 표를 찾아** 그 줄만 고치면 된다. 전부 한 줄짜리 숫자 변경이고, 되돌리기도 쉽다.

> 🔴 **여기 있는 값은 전부 "아직 안 정해진 것"이다.** 헤드리스 테스트로는 결론이 안 난다(`projectb-verify` §6) — 직접 해 보고 느낌으로 정하는 수밖에 없다. 지금 몰라도 되고, 나중에 거슬릴 때 고치면 된다.
>
> ⚠ 값을 바꾼 뒤에는 `bash scripts/deploy_web.sh` 한 번이면 반영된다.

## 1. 화면이 너무 작다 / 크다

| | |
|---|---|
| **파일** | `src/feel/camera_rig.gd` |
| **상수** | `ZOOM` |
| **현재** | `2.0` (16px 캐릭터가 화면에서 32px로 보인다) |
| **선택지** | `1.0`(원래 크기 = 아주 작음) · `2.0` · `3.0`(더 크게) |

🔴 **정수만 써라.** 1.5·2.5는 픽셀이 뭉개져 흐릿해진다.

⚠ **줌을 올리면 같이 따라오는 것들이 있다** — 보이는 범위가 줄어들기 때문이다:
- 캐릭터가 **빠르게** 보인다 → §2
- 맵이 **넓게** 느껴진다 → §2
- **안 보이는 적**이 달려온다 → §3
- 화면 흔들림이 **커진다** → 같은 파일 `SHAKE_MAX`(현 3.5)·`KICK_MAX`(현 4.5)를 줌 배율에 반비례로 조정

## 2. 캐릭터가 너무 빠르다 / 느리다 · 맵이 넓다

| | |
|---|---|
| **파일** | `data/jobs/warrior.tres` · `archer.tres` · `mage.tres` |
| **값** | `move_speed` |
| **현재** | 전사 100 · 궁수 110 · 법사 90 |

16px 전환 때 **일부러 안 건드렸다** — 월드 좌표(맵 크기)를 그대로 뒀기 때문이다. 줌 2배에서 화면상 2배 빨라 보인다면 **50 / 55 / 45**로 내리면 32px 시절 체감과 같아진다.

⚠ 이걸 내리면 맵 횡단 시간이 2배가 된다(마을이 넓게 느껴진다). 반대로 맵을 좁히려면 `village.tscn`의 노드 좌표를 전부 줄여야 해서 훨씬 큰 작업이다 — **이동속도부터 만져 보는 게 맞다.**

## 3. 안 보이는 적이 달려온다

| | |
|---|---|
| **파일** | `data/enemies/goblin_melee.tres` · `brute.tres` · `chaser.tres` |
| **값** | `aggro_range` |
| **현재** | 고블린·chaser 140 · 브루트 220 · 보스 520 |

줌 2배면 화면 반폭이 160px이라 140은 아슬아슬하다. 화면 밖에서 어그로가 걸리면 **70 / 110** 정도로 내린다.

## 4. 공격이 안 닿는다 / 너무 멀리 닿는다

| | |
|---|---|
| **파일** | `data/jobs/*.tres` |
| **값** | `attack_range` |
| **현재** | 전사 21 · 궁수 24 · 법사 28 (16px 전환으로 42/48/56에서 절반) |

🔴 **이 값 하나가 판정·스워시 크기·검기 파형 도달점을 동시에 움직인다**(`CombatMath.effective_attack_range` 단일 소스). 그래서 여기만 고치면 "맞는 곳 = 보이는 곳"이 자동으로 유지된다 — **다른 데서 사거리를 따로 조정하지 마라.**

## 5. 화살/마법이 너무 짧게 / 멀리 날아간다

| | |
|---|---|
| **파일** | `data/equipment/worn_bow.tres` · `worn_staff.tres` |
| **값** | `arrow_range` |
| **현재** | 활 110 · 지팡이 120 (16px 전환으로 220/240에서 절반) |

⚠ **이건 밸런스 변경이었다.** 근접을 절반으로 줄이면서 원거리만 그대로 두면 근접:원거리 비율이 5.2배 → 10배로 벌어져서 같이 줄였다. 답답하면 **150~220** 사이로 되돌려도 된다.

폭발 반경은 같은 파일 `blast_radius`(현 10, 원래 20).

## 아직 안 정한 큰 것 (결정이 필요할 때 보면 된다)

- **캐릭터 1개 + 무기가 직업** — 미착수. `job_id`가 하위 직업 **계열**의 뿌리라 GDD 변경(planner 승인 + critic 검증)이 선행 조건이다. 이번 개편의 최대 비용이고, 마감(2026-08-10)까지 남은 기간을 보고 정한다.
- **월드 좌표를 절반으로 줄일지** — 줄이면 화면이 32px 시절과 완전히 같아지지만, `village.tscn` 노드 좌표·마을 바닥 이미지·스폰 지점·맵 경계를 전부 변환해야 한다. §2 이동속도 조정으로 대부분 해결되는지 먼저 본다.
- **브랜치 머지** — `feat/game-feel-polish`(손맛·배경) · `feat/16px-scale`(16px 전환) 둘 다 `master` 미머지. 실기 확인 후 머지한다.
