## 1. 컨셉 한 줄

**혼자선 못 깨는 협동 파훼.** 미노가 한 명을 **비석에 결박**(못 피함)하고, 그 사이 **다른 한 명이 비석을 부숴** 구출한다. 핵심 = **A(버티기) + B(파괴)가 맞물려야만** 풀리는 상호 의존 — "내가 버텨야 쟤가 깬다".

- 코옵 **전용** · **정확히 2인** (host+guest). 역할은 지목/근접으로 매 발동 교대.
- 공통 루프 = **파훼 → 보스 경직 → 둘이 공동 딜**(테스트 랩 돌진→그로기 구조 재사용).
- 설계 기둥 = **"이건 못 피한다"를 확실히 인지시킨다.** 피할 것 같은데 못 피하면 조작 실패로 느껴진다 → 애초에 **구르기를 봉인**해 "붙잡히는 게 정상, 짝이 구하러 온다"로 읽힌다.

## 2. 국면 (시퀀스)

### 국면 1 — 결박 (불가피 · 순서 중요)
1. 보스가 한 명 **지목**.
2. 지목 대상 위로 **비석이 낙하** → 착지 순간 **붉은 영혼 줄이 즉시 완전 속박** — 이동·구르기·공격 **전부 봉인**. "못 피함"이 여기서 확정 (보스 돌진이 아니라 **비석+줄**이 붙잡는다).
3. **보스가 그 사람에게 달려와 달라붙어 공격 개시.**
4. 보스 공격이 시작되는 순간부터 → **A(속박된 자)는 연타(버티기) 시작.**

### 국면 2 — 버티기 & 구출 (A+B 맞물림)
- **A(속박):** 이동·구르기·공격 봉인, **연타키만** 먹힘 = 버티기. 연타 = ⓐ 저항시간 감소를 **늦추고** ⓑ **비석 자연회복을 정지**시킨다(= B의 진전을 열어줌).
- **B(자유):** 무기로 **비석 타격**(내구도 100→0) + 구르기로 **가시 회피** + **가시 파편 회수**.
- **위협 분담:** 보스 = A 담당(물고 늘어짐) · 비석 가시 = B 담당. → 화면이 깔끔하게 갈린다.

### 결말
- **성공(비석 내구도 0):** 비석 산산조각 → **보스가 A에게서 튕겨나가며 경직** + 줄 끊김 + A 해방(짧은 무적) → **둘이 공동 딜.**
- **실패(A 저항 0):** A가 HP 큰 덩이(≈40%) 잃고 **강제 해방** + 보스 살짝 회복. **진행은 계속**(전멸 아님 — 재도전 흐름 유지). ⚠ 단 2인 중 B가 이미 죽은 경우의 처리는 §8 미해결.

## 3. 왜 혼자선 안 되나 (맞물림 — 수치로 증명)

| 상황 | 결과 |
|---|---|
| **B 혼자** (A가 연타 안 함) | 비석 자연회복(+10/s)에 타격이 상쇄 → 내구도 안 내려감 + A 저항 소진 → **실패** |
| **A 혼자** (B가 안 침) | 내구도 그대로 → 저항만 끌다 소진 → **실패** |
| **둘 다** | A가 회복 막는 동안 B 타격이 그대로 박힘 → **~8초 파훼** ✅ |

## 4. 게이지 · 회피 · 아이템 (시작값 · 전부 튜닝 대상)

### 두 게이지
| 게이지 | 누구 | 방향 | 규칙 |
|---|---|---|---|
| **비석 내구도** | B가 깎음 | 100 → 0 (0=파괴) | B 타격 −6/타(≈2타/s=−12/s) · **자연회복 +10/s**(단 A 버티는 동안 회복 정지) |
| **A 저항시간** | A | 100 → 0 (0=실패) | 항상 감소(−6/s) · **A 연타 시 −3/s**(≈33초) |

- B 혼자 실질 −2/s → ~50초(제한 못 맞춤). 둘 다 −12/s → **~8.3초**.

### 회피 리듬 + 가시 파편(아이템)
- 비석이 **2.5s마다 붉은 가시 링** 방출(예고 0.7s). B가 안 피하면 피해+경직 → DPS 손실 → 파괴 지연. (8초 동안 ~3번 회피)
- 가시가 터진 자리에 **가시 파편**이 **3초 잔존** → B가 밟으면(**자동 회수**) **다음 3타 강타(−18) + 가시 면역**.
- → "피하고 딜 vs 파편 먹고 폭딜" 선택. 파편은 방금 가시 터진 자리라 **다음 예고와 겹칠 수 있어** 타이밍을 잰다. (회복 정지는 여전히 A 몫 → 협동 유지)

| 성공 `_on_solved()`(:410)→`_resolve(true)`(:444) | **내구도 0** → 같은 경로 + `boss.enter_groggy()`(boss.gd:321)로 경직·공동 딜 | 결말(성공) |
| 만료 `_expire()`(:303)→`apply_damage(FAIL_DAMAGE=9999)`(:521) | **저항 0** → `apply_damage(max_hp*0.4)` + 강제 해방 + 보스 소량 회복(즉사 아님) | 결말(실패) |
| 호스트 권한 `G_COOP_CALL/RES` + `if from_id!=HOST_ID`(:528/:552) | 동일 재사용 | 🔴 **netreview**(연타/타격 스팸·시퀀스 가드) |

> 두 게이지 값·타이밍 = §4. A 저항시간(win) = §9. **아트는 §6-3, dev는 이 표를 그대로 배선한다.**

## 9. 잠정 확정 기본값 (§8 🔵 해소 · 브레인스토밍 기반 · 실기 튜닝 대상)
