## 1. 컨셉 한 줄

**도끼를 든 근접 브루트.** 아레나에 **바위(지형)** 가 깔려 있고, 플레이어는 그 바위를 이용해 보스를 처벌한다. 핵심 재미 = **읽기 → 회피 → 처벌** 루프, 특히 **낙석 ↔ 돌진**이 물리는 미니 루프.

- def 전환: `keep_distance 150 → 0`(추격), `ghostly` off, `show_telegraph` on. (현 `wraith_boss.tres`는 카이팅·부유 망령 설정이라 갈아엎는다.)
- GDD §5 원칙 준수: **긴 텔레그래프 · 읽고 구르기로 대응 · 프레임 단위 반응 요구 금지**(웹 지연 공정성). 모든 예고 ≥ 구르기(0.25s)보다 충분히 김.
- "맞는 곳 = 보이는 곳"은 `boss_telegraph.gdshader`가 판정 기하(range·half_angle)에서 직접 그려 자동 보장.

## 2. 패턴 목록 (평상시 로테이션)

지원 형태 = `circle`(원) · `cone`(전방 부채꼴) · `spray`(N발 산탄). 패턴 선택기가 **거리별 역할 분리**(가까이=평타·중간=슬램·멀리=원거리)를 이미 함(`boss.gd:406`).

| # | 패턴 | 형태 | 거리 역할 | 페이즈 | 데이터만? | 상태 |
|---|---|---|---|---|---|---|
| P1 | 도끼 후려치기 | `cone` | 근접 | 1 | ✅ | 러프 (수치 TBD) |
| P2 | 내려찍기 | `circle` | 중거리 | 1 | ✅ | 러프 (기존 slam 개조) |
| P3 | **돌진 + 휘두르기** | 신규(코드) | 원거리→접근 | 1 | ❌ 코드 | **확정 (아래 §3)** |
| P4 | 낙석 | `spray` | 원거리/광역 | 1~2 | ✅ + 오브젝트 | 러프 (바위 생성 연동) |
| P5 | 도끼 회전 | `circle` | 근접(전방위) | 2? | ✅ | 러프 |

> 🔴 P3만 데이터로 안 된다 — 이동·스윕·분기(바위/헛참)가 있어 **돌진 전용 상태머신**이 필요하다(네트워크 리뷰 필수). 나머지는 `.tres` 인라인 `BossPatternDef`로 닫힌다.

## 3. 돌진 + 휘두르기 (시그니처 — 확정)

### 동작
**도끼를 몸 주위로 한 바퀴 휘두르며 직진.** 이동과 스윕이 한 몸이라 위협 = **돌진 선 + 스윕 반경** 둘 다.

### 회피 (공정성 확정)
- **차선 = 구르기:** 스윙이 "한 번"이라 타이밍 구르면 스윕 반경 밖으로 빠진다. (바위 없는 아레나에서도 피할 구멍 보장 — "무조건 맞음" 방지.)
- **최선 = 바위 유도:** 보스를 바위 쪽으로 유도하면 훨씬 이득.

### 분기 — 이 비대칭이 학습을 만든다
| 결과 | 무슨 일 | 엔딩 포즈 | 색 신호 |
|---|---|---|---|
| 🪨 **바위에 박음** | 돌진 끊김 + **휘두르기 안 나옴** + **그로기 3초**(파티 처벌창) | 도끼 잼·다운·**열림** | 초록/다운 |
| 💨 **바위 없음** | 스윕 완주(위협 다 나옴) → 스키드 후딜 → 추격 복귀 | 완주·**위협** | 붉은/발광 |

→ "박으면 저 무서운 스윙이 안 나온다"가 바위로 유도할 강력한 이유. 두 엔딩 실루엣이 **정반대**라 애니만 봐도 "바위 = 이득, 없으면 위험"이 각인된다.

### 상태머신 (랩의 dash 상태가 모델 — `test_lab.gd` CS_AIM/CS_DASH)
1. **예비 (windup, ~1.2s):** 뒷발로 땅 긁기 + 몸 낮추고 뒤로 당김 + 얼굴·도끼 목표 방향 **고정** + 도끼 옆으로 크게 빼기. 바닥에 **긁힘 선**(= 위험선, 경로 예고). 방향 잠금 순간 짧은 **플래시** = "지금 자리 잡아라".
2. **돌진 + 스윕:** 앞으로 기운 질주 + **수평 스쿼시**(빠름의 시각 언어) + 도끼가 몸 주위 한 바퀴. **잔상**(`afterimage.gd` 기존) + 스피드 라인 + **도끼 궤적 리본**(기존 칼 잔상 시스템 재사용).
3-A. **바위 충돌:** 🔴 교육 핵심 프레임 — **도끼가 호를 다 못 그리고 바위에 꽝 걸려 멈춤**(스파크 + 클랭). 관성 튕겨 뒤로, 별 뱅뱅(daze), 슬럼프. 화면 흔들림 + 바위 산산조각 + 히트스톱(feel 기존).
3-B. **헛참:** 스윕 완주 → 감속 스키드(팔로스루) → 돌아서기 → 짧은 후딜.

### 추가 요소 원칙 (juice 넣되 가독성 안 깸)
- **예비동작 과장** → 릴리스 선명 (스쿼시-스트레치).
- **색/발광 램프** → 눈에 보이는 타이밍 시계.
- **긁힘 선의 수직** = 회피 축 (선이 곧 "이쪽으로 비켜라"를 가르침).
- **①→② 관성 계승**(미끄러짐이 스윙을 낳음) — 없으면 "멈춰서 억지로 휘두른다"로 툭 끊긴다.
- **첫 헛참은 살짝 관대**(예고 조금 느리게) → 반복하며 자연히 바위 유도 학습.

## 3-1. 돌진 애니 상태 전이 + 배선 (읽고 바로 구현 가능)

🔴 **먼저:** 돌진은 `boss.gd`의 기본 공격 경로(`_play_attack_anim` = 예고 길이에 맞춘 **단일 클립**)를 **타지 않는다.** 이동·가변 길이·분기가 있어 **돌진 전용 서브상태**가 클립을 직접 몬다. 아래 표대로 상태를 추가한다.

### 상태 전이 표

| 상태 | 재생 클립 | 루프 | 이동 | 판정 | 다음 상태 | 전이 조건 |
|---|---|---|---|---|---|---|
| WINDUP *(기존 재사용)* | `charge_windup` | oneshot, telegraph_s에 맞춤 | 정지 | 없음 (긁힘 선 예고만) | CHARGE_DASH | 예고 종료 (`_state_left ≤ 0`) |
| **CHARGE_DASH** *(신규)* | `charge_dash` | **loop** | 고정 방향 직진(`charge_speed`) | 몸 주변 스윕(cone) **매 프레임** | CHARGE_HIT / RECOVER | 바위 충돌 → HIT · 이동상한/타임아웃 → RECOVER |
| **CHARGE_HIT** *(신규)* | `charge_hit` | oneshot | 급정지·리코일 | 스윕 **즉시 중단** | GROGGY | 클립 종료 |
| **GROGGY** *(기존 `enter_groggy` 재사용)* | 눕/슬럼프 daze 포즈 | 유지 | 정지·무방비 | 없음 (피격만 받음) | CHASE | 3초 경과 |
| RECOVER *(기존 재사용)* | `charge_recover` | oneshot | 스키드 감속(팔로스루) | 없음 | CHASE | 클립 종료 (`recover_s`) |

> "바위 O = HIT→GROGGY(처벌창)" / "바위 X = RECOVER(스킵)" 이 갈림이 §3 분기 표와 1:1로 맞는다.

### boss.gd에 얹는 법 (통합 지점 — 실제 심볼)
- **State enum 확장** (`boss.gd:77`): `CHARGE_DASH, CHARGE_HIT` 추가. WINDUP·RECOVER·GROGGY(=`groggy_left`)는 **기존 것 재사용.**
- **WINDUP 분기** (`_host_ai`의 `State.WINDUP`, 종료 시 `_fire_strike()`): 선택된 패턴이 **돌진이면** `_fire_strike()` 대신 `CHARGE_DASH`로 진입. (구분 = 아래 신규 필드.)
- **클립 직접 구동:** 각 상태 진입 시 `_play(&"charge_xxx", 1.0, true)`(force_restart) — 단일 클립 경로를 우회해 서브상태가 몬다.
- **그로기 재사용:** 바위 충돌 시 `enter_groggy(3.0)`(`boss.gd:321`) → `_update_life_feel`이 이미 눕는 포즈·무방비를 처리(신규 코드 최소).
- **ATTACK_ANIMS 등록** (`boss.gd:43`): `charge_dash` 등을 넣어 이동/idle 애니가 돌진 중 클립을 덮지 않게(`_is_attack_anim_playing` 게이트).
- **스윕 판정:** DASH 매 프레임 보스 주위 판정을 **호스트가 확정**(`EventBus.boss_strike` 재사용 또는 이동 콘). 🔴 프레임당 중복 dedup·권한 경계 = **netreview 대상.**

### BossPatternDef 신규 필드 (데이터로 못 넣는 돌진 파라미터)
- `is_charge: bool` *(또는 `shape == "charge"`)* — WINDUP 분기 스위치
- `charge_speed` · `charge_sweep_radius` · `charge_travel_max` · `groggy_s`(=3.0)

→ **아트는 §6 클립을, dev는 이 표 + 통합 지점을 그대로 배선하면 된다.**

## 4. 낙석 ↔ 돌진 루프 (미니 루프 — 이 보스의 정체성)

**낙석 피하기 → 바위가 지형으로 배치됨 → 돌진 유인 → 처벌.** 플레이어가 "바위를 무기로 쓰는" 능동성이 핵심. 그냥 굴러 피하는 것보다 훨씬 재밌다.

- **P4 낙석:** `spray`로 흩어진 N점에 바위 낙하. 착탄한 바위가 **아레나 지형 오브젝트로 남는다**(= 돌진 유도용).
- **열린 튜닝:** 바위 몇 개까지 쌓이나 · 수명(영구? TTL?) · 낙석 리듬 · 돌진 한 번 박으면 그 바위는 부서지나.

### 5-3. 코드 (`projectb-dev` + 🔴 `projectb-netreview`)

- **바위 오브젝트:** 낙석 스폰 → 지형화 → 돌진 충돌. 호스트/게스트 동기화.
